¿Qué tan rápido converge el error?

Se repite la simulación muchas veces con distintos valores de n y se mide el error absoluto medio. El error esperado decrece proporcional a 1/√n: para dividir el error entre 10 se necesitan 100 veces más ensayos.

¿Cómo leer este análisis?

  • Error absoluto medio: promedio de |frecuencia simulada − probabilidad teórica| en las repeticiones.
  • Error esperado: √(2/π) · √(p(1−p)/n), valor que predice la teoría para la desviación media de una proporción.
  • Si ambas curvas son casi paralelas, se confirma empíricamente que el error se comporta como O(1/√n).

P

Probabilidad clásica

Si todos los resultados son igualmente probables, P(A) = casos favorables / casos posibles. Se aplica al lanzamiento de los dados.

|

Probabilidad condicional

La regla del producto: P(A∩B) = P(A) · P(B|A). Al no devolver el primer fusible, la composición de la caja cambia.

n→∞

Ley de los Grandes Números

A medida que n crece, la frecuencia relativa f = éxitos / n converge a la probabilidad teórica p.

x̄

Estadística descriptiva

Media x̄ = Σxᵢ / n y varianza muestral s² = Σ(xᵢ − x̄)² / (n−1) de los resultados simulados.

±

Intervalo de confianza

Para una proporción, p ± 1,96·√(p(1−p)/n) contiene a la frecuencia simulada en ≈95 % de las corridas.

%

Error absoluto y relativo

Eabs = |f − p| y Erel = |f − p| / p. Cuantifican qué tan lejos queda la práctica de la teoría.

Proyecto académico

Acerca del proyecto

Aplicación web que compara la probabilidad teórica de un evento con la frecuencia relativa obtenida al simularlo múltiples veces, validando la Ley de los Grandes Números.

Planteamiento

Solemos calcular probabilidades con fórmulas, pero rara vez comprobamos si se cumplen en la práctica. ¿Ocurre que P(suma = 7) = 1/6 al lanzar los dados solo 10 veces? ¿Y 10.000? Este proyecto cierra esa brecha entre la teoría y la percepción empírica.

Flujo de uso

  1. Seleccionar el experimento (dos dados o fusibles).
  2. Definir el número de repeticiones.
  3. Visualizar valor teórico, frecuencia simulada y gráficas.
